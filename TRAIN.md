# Training AntiSite

This guide reproduces AntiSite from scratch on the three benchmarks (PECAN, Paragraph, MIPE).
Install everything first as described in the [README](README.md#installation).

The released checkpoints in [`release/checkpoints/`](release/checkpoints) were produced with this exact
pipeline. The processed datasets (PLM embeddings, ParaSurf features) are **not** shipped in the repo —
they are multi-GB and regenerated by the steps below from the benchmark structures.

## Pipeline overview

```
PDB structures + chain metadata
        │
        ▼  (1) ParaSurf precompute        →  cache/{dataset}/{split}/      256-d surface features
        ▼  (2) build_dataset              →  examples/{dataset}/{split}/   sequences + labels + features
        ▼  (3) build_embeddings (4 PLMs)  →  embeddings/{dataset}/{split}/ per-residue PLM embeddings
        ▼  (4) train / train_kfold        →  runs/{dataset}/               trained checkpoint
```

Steps (1)–(3) are run **once per (dataset, split)**; training then only reads tensors from disk.

---

## 1. Precompute ParaSurf 3D features

Run the ParaSurf surface-feature extractor on the antibody (receptor) structures. This produces the
256-d per-residue features used by the 3D path.

```bash
python -m antisite.teacher.precompute \
    --pdb-dir  test_data/pdbs/Expanded_dataset_Paragraph/Entire_antibody_experiment/TRAIN \
    --weights  weights/Paragraph_expanded_entire_dataset_best.pth \
    --out-dir  cache/Paragraph_expanded/TRAIN \
    --pattern  '*receptor*.pdb'
```

Repeat for each split (`TRAIN`, `VAL`, `TEST`). Helper scripts:
[`run_precompute_pecan.sh`](run_precompute_pecan.sh),
[`run_precompute_paragraph.sh`](run_precompute_paragraph.sh),
[`run_precompute_mipe.sh`](run_precompute_mipe.sh).

## 2. Build training examples

Fuse sequences, ground-truth paratope labels (4.5 Å heavy-atom criterion) and the cached ParaSurf
features into one tensor bundle per antibody.

```bash
python -m antisite.data.build_dataset \
    --pdb-dir   test_data/pdbs/Expanded_dataset_Paragraph/Entire_antibody_experiment/TRAIN \
    --meta      test_data/pdbs/Expanded_dataset_Paragraph/Preprocess/train_set.csv \
    --cache     cache/Paragraph_expanded/TRAIN \
    --out-dir   examples/Paragraph_expanded/TRAIN
```

## 3. Build PLM embeddings

Precompute per-residue embeddings for the four PLMs (AbLang2, ProtT5, ESM-2, IgT5).

```bash
python -m antisite.data.build_embeddings \
    --examples-dir examples/Paragraph_expanded/TRAIN \
    --out-dir      embeddings/Paragraph_expanded/TRAIN \
    --plms ablang2,prot_t5,esm2,igt5 \
    --batch-size 16 --gpu 0
```

All splits at once: [`run_embeddings.sh`](run_embeddings.sh).

---

## 4. Train

### Single dataset (PECAN / Paragraph)

```bash
python -m antisite.train.train \
    --train-examples     examples/Paragraph_expanded/TRAIN \
    --train-embeddings   embeddings/Paragraph_expanded/TRAIN \
    --val-examples       examples/Paragraph_expanded/VAL \
    --val-embeddings     embeddings/Paragraph_expanded/VAL \
    --out-dir            runs/Paragraph \
    --modality-dropout   0.5 \
    --cross-modal-layers 1 --cross-modal-heads 4 \
    --lambda-fused 1.0 --lambda-kl 0 --lambda-mse 0 \
    --track-head fused
```

### 5-fold cross-validation (MIPE)

```bash
python -m antisite.train.train_kfold \
    --train-val-examples   examples/MIPE/TRAIN_VAL \
    --train-val-embeddings embeddings/MIPE/TRAIN_VAL \
    --test-examples        examples/MIPE/TEST \
    --test-embeddings      embeddings/MIPE/TEST \
    --out-dir              runs/MIPE \
    --folds 5 \
    --modality-dropout   0.5 \
    --cross-modal-layers 1 --cross-modal-heads 4 \
    --lambda-fused 1.0 --lambda-kl 0 --lambda-mse 0
```

The best checkpoint (selected on validation PR-AUC of the fused head) is written to the output
directory. Training writes per-epoch metrics to `history.json` and a metrics chart to `metrics.png`.

## Released configuration

| Setting | Value |
|---|---|
| PLM stack | AbLang2, ProtT5, ESM-2, IgT5 |
| Modality dropout `p` | 0.5 |
| Cross-modal attention | 1 layer, 4 heads |
| Loss | binary cross-entropy (fused head only; `λ_kl = λ_mse = 0`) |
| Optimizer | Adam, lr `1e-4`, weight decay `1e-5` |
| Batch size | 8 |
| Early stopping | val PR-AUC, patience 7 |

See the paper's Supplementary Information for the full ablations behind these choices.
