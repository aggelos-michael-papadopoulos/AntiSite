# Training AntiSite

This guide documents the main from-scratch pipeline for PECAN, Paragraph, and MIPE, plus the corrected
AACDB example-building path. Install everything first as described in the
[README](README.md#installation).

The processed datasets (PLM embeddings, ParaSurf features) are **not** shipped in the repo — they are
multi-GB and regenerated by the steps below from the benchmark structures. The released checkpoints
predate the 2026-07-30 sequence/chain-role correction and represent the historical inputs; see
[`Data/README.md`](Data/README.md) before comparing a corrected retraining run with them.

## Pipeline overview

```
PDB structures + chain metadata
        │
        ▼  (1) ParaSurf precompute        →  cache/{dataset}/{split}/      256-d surface features
        ▼  (2) build_dataset              →  examples/{dataset}/{split}/   sequences + labels + features
        ▼  (3) build_embeddings (2 PLMs)  →  embeddings/{dataset}/{split}/ per-residue PLM embeddings
        ▼  (4) train / train_kfold        →  runs/{dataset}/               trained checkpoint
```

Steps (1)–(3) are run **once per (dataset, split)**; training then only reads tensors from disk.

The tracked CSVs under `Data/` are the corrected chain-metadata source of truth.

---

## 1. Precompute ParaSurf 3D features

Run the ParaSurf surface-feature extractor on the antibody (receptor) structures. This produces the
256-d per-residue features used by the 3D path.

```bash
python -m antisite.parasurf.precompute \
    --pdb-dir  test_data/pdbs/Expanded_dataset_Paragraph/Entire_antibody_experiment/TRAIN \
    --weights  ParaSurf/Paragraph_expanded_entire_dataset_best.pth \
    --out-dir  cache/Paragraph_expanded/TRAIN \
    --pattern  '*receptor*.pdb'
```

Repeat for each split (`TRAIN`, `VAL`, `TEST`). Helper scripts:
[`scripts/run_precompute_pecan.sh`](scripts/run_precompute_pecan.sh),
[`scripts/run_precompute_paragraph.sh`](scripts/run_precompute_paragraph.sh),
[`scripts/run_precompute_mipe.sh`](scripts/run_precompute_mipe.sh).

## 2. Build training examples

Fuse sequences, ground-truth paratope labels (4.5 Å heavy-atom criterion) and the cached ParaSurf
features into one tensor bundle per antibody.

```bash
python -m antisite.data.build_dataset \
    --pdb-dir   test_data/pdbs/Expanded_dataset_Paragraph/Entire_antibody_experiment/TRAIN \
    --meta      Data/Paragraph/train.csv \
    --cache     cache/Paragraph_expanded/TRAIN \
    --out-dir   examples/Paragraph_expanded/TRAIN \
    --overwrite
```

Use the corresponding `Data/<dataset>/<split>.csv` for each split. Rebuild every existing example and
embedding after changing sequence or chain metadata; otherwise stale tensors silently preserve the
old inputs. ParaSurf caches are keyed to physical PDB residues and may be reused after verifying they
cover the corrected selected chains.

AACDB stores receptor and antigen chains in one combined PDB. From the repository root, place the
combined structures under `test_data/pdbs/AACDB/all_structures/`, then build each preserved split with
the same builder and the combined-layout flag, for example:

```bash
python -m antisite.data.build_dataset \
    --pdb-dir test_data/pdbs/AACDB/all_structures \
    --meta Data/AACDB/train.csv \
    --cache cache/AACDB/parasurf \
    --out-dir examples/AACDB/TRAIN \
    --combined-pdb --overwrite
```

## 3. Build PLM embeddings

Precompute per-residue embeddings for the two PLMs (ProtT5, ESM-2).

```bash
python -m antisite.data.build_embeddings \
    --examples-dir examples/Paragraph_expanded/TRAIN \
    --out-dir      embeddings/Paragraph_expanded/TRAIN \
    --plms prot_t5,esm2 \
    --batch-size 16 --gpu 0 --overwrite
```

All prepared Paragraph, PECAN, and MIPE splits at once:
[`scripts/run_embeddings.sh`](scripts/run_embeddings.sh).

---

## 4. Train

### Single dataset (Paragraph / PECAN / AACDB)

```bash
python -m antisite.train.train \
    --train-examples     examples/Paragraph_expanded/TRAIN \
    --train-embeddings   embeddings/Paragraph_expanded/TRAIN \
    --val-examples       examples/Paragraph_expanded/VAL \
    --val-embeddings     embeddings/Paragraph_expanded/VAL \
    --out-dir            runs/Paragraph \
    --enabled-plms       prot_t5 esm2 \
    --modality-dropout   0.5 \
    --cross-modal-layers 1 --cross-modal-heads 4 \
    --lambda-fused       1.0 \
    --track-head fused
```

### 5-fold cross-validation (MIPE)

```bash
python -m antisite.train.train_kfold \
    --train-val-examples   examples/MIPE/TRAIN_VAL \
    --train-val-embeddings embeddings/MIPE/TRAIN_VAL \
    --test-examples        examples/MIPE/TEST \
    --test-embeddings      embeddings/MIPE/TEST \
    --out-dir              runs/MIPE \
    --folds 5 \
    --enabled-plms         prot_t5 esm2 \
    --modality-dropout     0.5 \
    --cross-modal-layers   1 --cross-modal-heads 4 \
    --lambda-fused         1.0
```

The best checkpoint (selected on validation PR-AUC of the fused head) is written to the output
directory. Training writes per-epoch metrics to `history.json` and a metrics chart to `metrics.png`.

## Released configuration

| Setting | Value |
|---|---|
| PLM stack | ProtT5, ESM-2 |
| Modality dropout `p` | 0.5 |
| Cross-modal attention | 1 layer, 4 heads |
| Loss | auxiliary BCE + fused BCE (`L_aux + λ_fused L_fused`, `λ_fused = 1.0`) |
| Optimizer | AdamW, lr `1e-4`, weight decay `1e-5` |
| Batch size | 8 |
| Early stopping | val PR-AUC, patience 7 |

See the paper's Supplementary Information for the full ablations behind these choices.
